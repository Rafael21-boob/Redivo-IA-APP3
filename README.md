Como eu fiz

Analisei os arquivos que ja estavam implementados para entender o funcionamento do projeto. Depois desenvolvi a classe Cat usando a classe Dog como referencia e por fim completei o enum FurColor seguindo o mesmo padrao utilizado nos outros enums.

Como eu testei

Fiz alguns testes criando gatos com caracteristicas diferentes e executando os metodos da classe para verificar os resultados. Tambem utilizei varias chamadas do metodo loseLife para conferir se a quantidade de vidas era atualizada corretamente e se as informacoes exibidas estavam corretas.

Cat

Na classe Cat foram adicionados todos os atributos solicitados, o construtor, os getters e os metodos makeSound, sleep, move, purr, loseLife e displayInfo.

FurColor

No enum FurColor foram cadastradas todas as cores pedidas na atividade. Tambem foram implementados os metodos para retornar o codigo, retornar o nome de exibicao e localizar uma cor a partir de um codigo informado.
